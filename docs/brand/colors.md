# Cores

A paleta Matheus Libonatti combina uma base neutra de alto contraste com três sinais de intenção. Os valores oficiais e suas variáveis reutilizáveis estão em [`tokens.css`](./tokens.css).

| Token | Hex | Função |
|---|---|---|
| Black | `#080808` | Fundo principal e texto sobre áreas claras |
| Soft Black | `#111111` | Cards e superfícies elevadas |
| Mineral White | `#F2F1ED` | Texto principal e fundos editoriais |
| Interface Gray | `#979792` | Metadados e texto secundário |
| Signal Lime | `#D9FF43` | Marca, disponibilidade e destaques |
| Action Orange | `#FF4D00` | Ações, contato e conversão |
| Digital Violet | `#9C7CFF` | Tecnologia, projetos e experimentação |

## Contraste

- Use Mineral White sobre Black ou Soft Black para textos longos.
- Use Black sobre Signal Lime e Action Orange.
- Interface Gray deve ficar restrito a texto secundário em tamanho confortável.
- Não dependa somente da cor para comunicar estado; combine-a com texto, ícone ou padrão.
- Todo novo par de cor deve atender pelo menos ao nível WCAG AA.

Uma seção deve usar apenas uma cor de sinal como protagonista. Isso preserva a hierarquia e evita que a interface pareça promocional demais.
