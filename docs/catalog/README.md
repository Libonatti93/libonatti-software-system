# Sistema de catálogo

Este documento define o padrão para transformar projetos reais em cases comerciais consistentes, localizados e preparados para SEO.

## Objetivo

Cada case deve provar experiência real, explicar valor de negócio e ajudar um potencial cliente a reconhecer que a mesma capacidade pode resolver seu problema — sem transformar o portfólio em uma coleção de screenshots.

## Rotas

```text
/pt-br/projetos/{slug}/
/es/proyectos/{slug}/
/en/projects/{slug}/
```

As três versões devem conter HTML completo, conteúdo localizado e referências `hreflang` recíprocas.

## Estrutura editorial

1. Contexto e status do produto.
2. Problema de negócio.
3. Usuários envolvidos.
4. Jornada antes e depois.
5. Solução e capacidades.
6. Diferencial proprietário.
7. Arquitetura e integrações.
8. Evidências verificáveis.
9. Resultados reais, quando autorizados.
10. CTA adaptado ao segmento.

## Dados mínimos por projeto

```text
nome
segmento
ano
status
papel de Matheus
problema
publicos
capacidades
diferencial
stack
integracoes
url publica
imagens autorizadas
metricas autorizadas
roadmap
restricoes de confidencialidade
```

## Princípios

- Conteúdo deve priorizar quem avalia a contratação.
- Não inventar métricas, funcionalidades ou resultados.
- Separar claramente produção, protótipo e roadmap.
- Não expor dados pessoais, credenciais, registros internos ou segredos comerciais.
- Traduzir intenção e contexto, não apenas palavras.
- Evitar competir pelas palavras-chave do cliente.
- Usar termos comerciais relacionados ao serviço que queremos vender.
- Manter uma linguagem visual própria para cada segmento sem perder a marca Libonatti.

## SEO

Cada página deve receber:

- título e description próprios;
- canonical absoluto quando o domínio oficial estiver conectado;
- `hreflang` para `pt-BR`, `es-419`, `en` e `x-default`;
- Open Graph localizado;
- imagem social;
- headings descritivos;
- links internos para serviço, blog e contato;
- imagem com nome e texto alternativo descritivos;
- inclusão no sitemap;
- validação no Search Console.

## Case 001

**Nogueira Cardiologia** inaugura o catálogo como plataforma SaaS vertical para saúde, incluindo aquisição, portal do paciente, agendamento, pagamentos, exames e CRM próprio.
